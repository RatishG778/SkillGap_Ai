# CareerOS AI — Architecture

## Vision

CareerOS AI is an adaptive placement preparation platform that continuously determines the best next action for a student based on:

- Current skills
- Target role
- Assessment performance
- Learning history
- Project evidence
- Interview performance
- Job requirements

## Core Loop

Student
→ Assessment
→ Skill Profile
→ Gap Analysis
→ Recommendation
→ Learning
→ Practice
→ Evaluation
→ Updated Skill Profile

## Initial Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- PostgreSQL

### AI
- Provider-independent AI layer
- Local models supported later

## Initial Product Scope

1. Student onboarding
2. Data Analyst target role
3. Diagnostic assessment
4. Skill graph
5. Skill gap engine
6. Personalized roadmap
7. AI teacher
8. Adaptive learning loop

## Explicitly Out of Scope for V1

- Recruiter portal
- College management system
- Automated job applications
- Mobile application
- Multi-agent architecture
- Custom foundation model
- Large-scale marketplace
