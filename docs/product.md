# CareerOS AI — Product Definition

## Core Problem

Students have access to many learning resources but struggle to determine:

- What they should learn
- What they already know
- What they are weak at
- What they should practice
- Which projects they should build
- When they are actually job-ready

## Core Solution

CareerOS AI creates an adaptive preparation path for each student.

## Initial Target User

College students preparing for placements.

## Initial Career Track

Data Analyst.

## Core Product Question

"What should this student do next to become more job-ready?"

## Primary Differentiator

Adaptive decision-making rather than a static course roadmap.

## MVP Success

A student can:

1. Create a profile
2. Select Data Analyst
3. Complete a diagnostic
4. Receive a skill profile
5. See skill gaps
6. Receive a personalized roadmap
7. Learn
8. Practice
9. Get evaluated
10. Receive an updated recommendation
